# SmartStock Inventory System
## Overview
The SmartStock system is a Python based inventory managment system built using Tkinter.
It allows users of the system to add, edit, remove and monitor both perishible and electronic items whith features such as:
- Low Stock Alerts
- Expiry date detection (for perishable items only)
- Inventory value calculation
- Transaction history tracking
- Dashboard summary view

## Requirements
Before running this program please make sure you have accsess to:
- Python 3 (recomended 3.8+)

## How to Download from GitHub
1. Go to the project repository on GitHub
2. Click the green **Code** button
3. Select **Download ZIP**
4. Extract the ZIP file to the desired location on you computer

## How to run the program (Visual Studio Code)
1. Open the project folder
2. Locate the main python file (`SmartStock.py`)
3. Open the file using Visual Studio Code
4. Run the program

## How to run the program (Terminal/Command Prompt)
1. Open the project folder
2. Locate the main python file (`SmartStock.py`)
3. Open a terminal or command prompt in that folder
4. Run the program using :
   `python smartstock.py`

## Using the Applictaion
- Add Stock → Add new products
- Edit Stock → Make changes to any existing items
- Remove Stock → Delete any existing items
- Smart Alerts → View low stock and expiring items
- Dashboard View → Summary of the system
- Value Calculation → Total stock value
- Transaction History → View all changes made in the system

## Saving and Accessing Data
- Click the **Save** button to save all inventory data in the `save.json` file
- The system will automatically load data on startup from the `save.json` file
